# 多项目与管理后台（V4.7）

## 一、一个人可以同时跑几部剧

### 之前为什么像「只能有一个项目」

后端从来没限制过：`POST /api/projects` 每建一次都写一条新记录，`/api/home` 也是全量返回（实测连建三部得到 #001 / #002 / #003）。
真正的问题在前端：创作页是 tabBar 页，走到第 2 步（设定）后切走再切回来**还是那一步**，也没有任何「另开一部」的入口。用户想开第二部只能反复点「返回改剧名」再手动清空，很容易判断成「系统只允许一个项目」。

### 现在怎么走

| 入口 | 位置 | 行为 |
|---|---|---|
| 首页「新建 +」 | 我的剧组标题右侧 | 跳创作页并**复位**成空白表单 |
| 首页「用这个名字开剧」 | 首屏输入框下方 | 带上剧名 + 复位 |
| 项目页「＋ 新建」 | 项目头左上角 | 跳创作页并复位 |
| 创作页「另开一部 / 清空重填」 | 标题下方状态条 | 原地复位，不跳页 |

切换已有的剧：

- 创作页点「N 部剧在手上 · 切换」→ 底部抽屉列出全部项目，点一条直接进。
- 项目页点「⇄ 我的剧组」→ 同样的抽屉，当前这部标「当前」，换剧用 `redirectTo`，返回时不会堆一串项目页。

设计上的取舍：

- 复位只清表单（剧名、创意、正文、报价、创作来源），**不清已加载的风格库和模型目录**，否则每次新建都要再等一次加载。
- 切换项目不销毁任何东西：每部剧的素材、剧本、分镜、成片都挂在各自 `project_id` 下，换剧只是换视图。

## 二、管理员账号

### 管理员与普通用户的区别

只有一位：`users.role === 'admin'`。

- 登录后 `/api/me` 返回 `is_admin: true`；
- 「我的」页据此渲染「管理后台」入口，普通用户**看不到**这个入口（不是置灰，是不渲染）；
- 所有 `/api/admin/*` 接口在服务端再校验一次，普通用户带自己的 token 访问一律 403。

也就是说，就算有人改了小程序前端，把入口画出来，服务端也不会认。

### 第一个管理员怎么来

系统里没有管理员时，服务端**启动时**生成一次性激活码，只打印在启动日志里：

```
管理员激活码（仅本次可见，用于创建第一个管理员账号） code: XXXXX-XXXXX
```

在小程序里：我的 → 管理后台 → 填激活码 + 手机号 + 密码 → 创建并直接进入。
激活码用过即作废，之后用手机号 + 密码登录。

为什么不把激活码做成接口返回：那等于 `/api/admin/bootstrap` 谁先扫到谁就是站长。日志只有能进控制台的人看得到。

### 也可以用环境变量直接配好

在云托管控制台设置：

| 变量 | 作用 |
|---|---|
| `ADMIN_PHONE` | 管理员手机号 |
| `ADMIN_PASSWORD` | 管理员密码（≥6 位） |

两个都配了，启动时自动建好/校正这个账号，不需要激活码。
`ADMIN_TOKEN` 仍然有效，等价于超级管理员，用于老的网页控制台 `admin.html` 和运维脚本。

### 小程序里的管理后台能做什么

| Tab | 能力 |
|---|---|
| 概览 | 用户数（今日新增 / 管理员数）、项目数、在账点数、累计充值、已消耗点数、生成次数 |
| 用户 | 按昵称/手机号/ID 搜索；看余额与作品数；调点数（正加负扣，落流水）；停用/恢复；设为/取消管理员 |
| 兑换码 | 批量生成（面额 + 数量），点一下复制 |
| 工具 | 模型探活（不扣用户点数）、算力网关状态（密钥只显示脱敏值） |

### 几条硬约束（都有测试锁着）

1. **不能把最后一个管理员降级**，也不能取消自己 —— 否则系统再没有管理员，只能改数据盘。
2. **不能扣成负余额**：调账前先算账，扣完为负直接拒绝并告诉他当前余额。
3. **停用立刻生效**：被停用的账号连未过期的 token 一起失效，不等过期。
4. **公开接口不回吐激活码**：`GET /api/admin/bootstrap` 只回答「还需不需要激活」。
5. **列表不泄露凭据**：用户列表不含密码哈希、盐、openid。
6. **换密钥仍走网页控制台**：小程序的网关卡片是只读的，避免密钥在手机上被截屏带走。

## 三、相关接口

```
GET  /api/admin/bootstrap        引导状态（公开，不含激活码）
POST /api/admin/bootstrap        用激活码创建第一个管理员（公开，一次性）
POST /api/admin/login            管理员手机号 + 密码登录
GET  /api/admin/stats            概览
GET  /api/admin/users?q=&offset= 用户列表
GET  /api/admin/users/:id        用户详情（含最近 20 条流水）
POST /api/admin/users/:id/points 调点数 {delta, note}
POST /api/admin/users/:id/status 停用/恢复 {status}
POST /api/admin/users/:id/role   设为/取消管理员 {role}
```

鉴权：`X-Admin-Token`（环境变量里的令牌）**或** `Authorization: Bearer <管理员登录态>`，二者其一。
