# 上传与内测指南

> 回答两个问题：**能不能代你上传提审**、**能不能用微信登录测试版内测**。
> 结论先给：上传可以做到「一条命令」，但密钥要你下、提审按钮要你点；内测能做，但手机必须先连得上后端。

---

## 0. 直接回答

### 问题 1：能不能用 AppID + AppSecret 直接替你上传挂审？

**不能，但不是因为我不帮你跑命令，而是微信的机制决定的：AppSecret 根本不是上传凭证。**

| 名称 | 长什么样 | 用途 | 谁能拿到 |
|---|---|---|---|
| AppID | `wxe3380ec60a48931d` | 小程序身份标识，公开 | 谁都能看 |
| AppSecret | `a47e6c99…`（32 位） | **服务端**换 openid / 手机号 / 支付签名 | 只有你和服务端 |
| 代码上传密钥 | `private.wxe338….key` 文件 | **只有它能上传代码** | 管理员登录后台才能生成/下载 |

所以流程只能是：

1. **你**：登录 <https://mp.weixin.qq.com> → 管理 → 开发管理 → 开发设置 → 小程序代码上传 → 生成并下载密钥（顺带把 IP 白名单关掉，或加上你电脑的公网 IP）；
2. **你**：把 `.key` 放到 `miniprogram/private.wxe3380ec60a48931d.key`（已加进 `.gitignore`，不会被提交）；
3. **我**：跑 `npm run mini:upload`，代码就上传成「开发版」；
4. **你**：后台「版本管理 → 开发版本」→ 选为体验版 / 提交审核 / 审核通过后发布。

第 3 步我完全能代跑（脚本已写好，见第 3 节）。第 4 步没有任何接口可代做——微信只给第三方平台服务商（需要企业资质 + 授权）开放提审接口，给个人开发者的一律是后台手动操作。

### 问题 2：能不能用微信登录测试版，仅供内测？

**能，而且有两种，但前提是手机能访问到后端。** 你现在 `config.js` 里是 `http://127.0.0.1:8787`，手机上这个地址指的是手机自己，必然白屏。

| 方式 | 谁能打开 | 需要什么 | 适合 |
|---|---|---|---|
| **预览码**（开发版） | 只有管理员/开发者本人 | 电脑开着服务 + 手机同一 WiFi | 自己验功能，改完立刻看 |
| **体验版** | 管理员 + 你添加的体验成员 | 公网 HTTPS 域名（已备案）+ 服务器 | **给别人内测，推荐** |

下面第 4 节给两种的具体操作。

## 1. 先把「提审前」和「内测期」分开

代码里有几个开关，内测和提审的要求不一样：

| 开关 | 位置 | 内测期 | 提审前 |
|---|---|---|---|
| `mockRecharge` | `miniprogram/config.js` | `true` 可留（点了即到账，方便测充值） | 虚拟支付商户号没下来就改 `false`，入口变「暂未开放」 |
| `ADMIN_TOKEN` | `server/.env.local` | **必须设**，否则 `/admin.html` 一律 403 | 保持 |
| `DATA_DIR` | `server/.env.local` | 指向固定目录（别用临时目录，否则重启丢数据） | 保持 |
| `baseUrl` | `miniprogram/config.js` 的 `hosts` | 见第 4 节 | `release` 必须是正式 https 域名 |
| 邀请入口 | `pages/mine/mine.wxml` | 可留 | 若审核质疑诱导分享，先删菜单项 |

## 3. 路线 B：命令行上传（我可以代跑）

已内置脚本 `server/scripts/mini_upload.js`（封装微信官方 `miniprogram-ci`）。

**你先做**：下载密钥 → 存成 `miniprogram/private.wxe3380ec60a48931d.key`。

**然后任选**：

```bash
cd server

npm run mini:doctor      # 体检：密钥位置对不对、依赖装没装、三个环境地址是否合规
npm run mini:lan         # 手机内测：打印电脑局域网 IP，直接告诉你 config.js 那行怎么改
npm run mini:preview     # 生成预览二维码 → miniprogram/dist/preview-日期.png
npm run mini:upload      # 上传开发版（版本号默认 1.0.261104 这种日期式）
npm run mini:upload -- --version 1.0.1 --desc "修复首页加载"
```

`mini:preview` 生成的二维码用微信扫就能打开（开发版），改完代码重跑一次即可，比开工具快。

**报错对照**：

| 报错 | 原因 | 处理 |
|---|---|---|
| `invalid ip` / `ip not in whitelist` | 开了 IP 白名单 | 后台「小程序代码上传」关掉白名单，或把本机公网 IP 加进去 |
| `privateKey ... no such file` | 密钥路径不对 | 跑 `npm run mini:doctor` 看它期望的路径 |
| `appid` / 密钥不匹配 | 密钥不是在 `wx7575ac…` 这个号下生成的 | 换号重新生成 |
| `Error: 请先登录` | 用了工具 CLI 但没登录 | 改用本脚本（走密钥，不需要登录） |

## 4. 手机内测：两条路

> **V4.7 起 `develop` 默认直连云端**，手机扫码直接就能用，不用再改代码。
> 只有你要连「本机后端」时才需要下面的 4.1。

### 4.1 连本机后端：本地存储覆盖（不用改代码）

```bash
cd server
npm run mini:lan        # 假设输出 192.168.1.123
```

在**开发者工具控制台**执行（只对开发版生效，不会影响别人、也不用重新上传）：

```js
wx.setStorageSync('dev_host', 'http://192.168.1.123:8787');
```

想换回云端：`wx.removeStorageSync('dev_host')`。

然后：`npm run mini:preview` → 手机（同一 WiFi）扫码 → 打开后从右上角「…」→「开发调试」。
这一步是让微信跳过「合法域名」校验，**只在开发版 + 打开调试时有效**。

限制：只有管理员/开发者本人能扫开；电脑必须开着；换 WiFi 后 IP 会变，要重新 setStorage。

> 历史教训：以前是把 `develop` 直接改写成局域网 IP，一旦换网、出门或后端没起，
> 手机上就只剩一句「网络异常」，且看不出原因。现在改成本地存储覆盖，默认值永远是云端。
> 详见 `docs/网络异常排查.md`。

### 4.2 给朋友内测：体验版 + 公网 HTTPS

体验版**一定**校验 request 合法域名，必须是 **https + 已备案**，所以要先有域名和服务器：

1. **域名备案**（个人可备，通常 7–20 个工作日）；没备案的域名微信不让填。
2. **一台小服务器**（2 核 2G 足够），装 Node 22。
3. **部署后端**（二选一），确认 `curl http://127.0.0.1:8787/health` 返回 200：
   - **Docker（推荐，仓库已带 `Dockerfile` + `docker-compose.yml`）**：
     ```bash
     # 服务器上：装好 docker 后，把整个工程目录传上去（含 server/、web/）
     docker compose up -d          # 数据落在 server/data，容器重建不丢
     docker compose logs -f        # 看启动日志
     ```
   - **直接跑**：`cd server && npm start`，用 systemd / pm2 常驻。

   > 注意 `web/` 目录要一起传：管理后台 `/admin.html` 由服务端静态托管，缺了它后台打不开。
4. **Nginx 反代 + 证书**（certbot 免费签）：

```nginx
server {
  listen 443 ssl;
  server_name api.你的域名.com;
  ssl_certificate     /etc/letsencrypt/live/api.你的域名.com/fullchain.pem;
  ssl_certificate_key /etc/letsencrypt/live/api.你的域名.com/privkey.pem;
  location / { proxy_pass http://127.0.0.1:8787; proxy_set_header Host $host; }
}
```

5. **后台加域名**：开发管理 → 开发设置 → 服务器域名 → request 合法域名：`https://api.你的域名.com`（一个月只能改 5 次，一次填全）。
6. **改小程序配置**：`config.js` 的 `hosts.trial` / `hosts.release` 改成这个域名。
7. **上传**：`npm run mini:upload -- --version 1.0.0 --desc "内测"`。
8. **设体验版**：后台「版本管理 → 开发版本 → 选为体验版」，页面会给出体验版二维码。
9. **加体验成员**：成员管理 → 体验成员 → 输入对方微信号（对方微信需已绑定该微信号；名额上限以后台页面显示为准，个人主体通常比企业主体少）。加不了就先让朋友用你的手机看，或改用「预览码 + 同一 WiFi」。

体验版二维码不等于公开二维码：只有管理员和体验成员能打开，**别人扫了会提示无权限**——正好符合「仅供内测」。

### 4.3 内测期间建议先关掉/留意的

- **别用临时 `DATA_DIR`**：内测数据要留着看，固定成 `server/data`。
- **邀请奖励**：内测号互邀会被「同设备 / 同 IP / 需完成首部作品」拦住，这是设计如此，不是 bug；真要演示就在后台把「每日笔数上限」调高、用两台不同网络的手机。
- **内容安全**：真实 AppID 下机审走微信接口，`WX_APPID`/`WX_SECRET` 已配好，内测就能看到真实拦截效果（涉政/涉黄文案会被挡）。
- **AI 生成耗时**：mock 模式下秒出，真实算力下单个镜头几十秒，内测别误判为卡死。

## 6. 一句话总结

**上传**：密钥你下 → 命令我跑 → 体验版/提审你点。
**内测**：自己测用「局域网 + 预览码」，给别人测用「体验版 + 已备案域名」；两者都必须先把 `127.0.0.1` 换掉。
