# 上传本地文件报「隐私政策」错误：原因与修复

## 现象

「改编我的素材」页点「上传本地文件」，弹出「没能选到文件」，或者干脆没反应。
错误原文（在 `errMsg` 里）通常是这两句之一：

```
chooseMessageFile:fail api scope is not declared in the privacy agreement
chooseMessageFile:fail privacy permission is not authorized
```

## 为什么会被拦

`wx.chooseMessageFile`（选文件）、`wx.chooseMedia`（相册/相机）从基础库 2.32.3 起属于
**隐私接口**。微信在调用前会做两道检查：

| 检查 | 不通过时 | 该谁修 |
|---|---|---|
| **小程序后台**是否在《用户隐私保护指引》里声明了这个用途 | `api scope is not declared` | 管理员去后台勾选并提交审核 |
| **用户**是否同意了这份指引 | `privacy permission is not authorized` | 代码侧弹窗引导用户同意 |

这两件事必须都做。只做代码侧、后台没声明 → 用户点了同意也没用；
只做后台、代码侧没弹窗 → 用户没有被问过，接口直接拒绝。
**而且是两个不同的修法，所以不能再混成一句「上传失败」**。

## 一、代码侧（已随 V4.14 修好，无需你操作）

- `miniprogram/utils/privacy.js`：新增隐私闸门
  - `privacy.init()` 在 `App.onLaunch` 注册 `wx.onNeedPrivacyAuthorization`，任何隐私接口被拦都能接住；
  - `privacy.ensure()` 在调隐私接口前先要授权：已同意直接放行，未同意就弹窗，同意后**原调用自动继续**，用户不用再点一次；
  - `privacy.explain(err)` 把微信的 errMsg 翻译成两类可执行提示（"后台没声明" / "还没同意"）。
- `miniprogram/components/privacy-gate/`：底部弹窗，同意按钮用的是微信唯一认可的
  `open-type="agreePrivacyAuthorization"`（`wx.showModal` 的确定按钮授予不了授权）。
- 挂载位置：`create`（创作/改编）、`project`（素材与资产）、`login` 三个页面。
- `utils/pickFile.js` 先过 `privacy.ensure()`；`project` 页的选图/选视频同样先过闸门
  （旧实现连 `fail` 回调都没写，所以表现是"点了没反应"）。

自检：`npm run mini:check` 第 16 组会检查以上每一项是否存在。

## 二、小程序后台（**需要管理员去点，代码替不了**）

1. 登录 [mp.weixin.qq.com](https://mp.weixin.qq.com) → 设置 → **服务内容声明** → 用户隐私保护指引。
2. 点「更新」，在「收集的信息」里勾上本项目真正用到的项：

   | 用途 | 对应接口 | 是否必须 |
   |---|---|---|
   | 选中的文件 | `wx.chooseMessageFile`（上传小说/剧本） | ✅ 必须 |
   | 相册（仅写入）/ 摄像头 | `wx.chooseMedia`（上传参考照片、参考视频） | ✅ 必须 |
   | 手机号 | `getPhoneNumber`（手机号登录） | 用到就勾 |

3. 填写「使用目的」，例如：*用于读取你选择的剧本文件并生成短剧，文件仅用于本项目的内容生产。*
4. 提交后一般 **1 个工作日内**审核通过，通过后立即生效（不需要重新发版）。

## 三、验证清单

- [ ] 后台《用户隐私保护指引》里能看到「选中的文件」「相册」两项，状态是「已通过」
- [ ] 真机（不是开发者工具）首次点「上传本地文件」→ 弹出底部同意框 → 点「同意并继续」→ 文件选择器直接弹出
- [ ] 拒绝一次后再点上传 → 还能再次弹出来（不是永久拒绝）
- [ ] 已同意后连续上传 3 次，不再重复弹窗
- [ ] 「我的 → 隐私政策」能打开完整指引（`wx.openPrivacyContract`）

## 四、如果还是失败

按 errMsg 分流：

| errMsg 关键字 | 含义 | 处理 |
|---|---|---|
| `api scope is not declared` | 后台没声明用途 | 回到第二节勾选并提交 |
| `privacy permission is not authorized` | 用户拒绝过 | 让用户在弹窗里点同意；或引导到「设置 → 隐私 → 授权管理」 |
| `cancel` | 用户自己取消了选择 | 正常行为，不提示错误 |
| `fail file not found` | 临时文件已失效 | 重新选一次 |
| `exceed max size` | 超过 40MB | 拆分文件或直接粘贴正文 |

## 五、顺带说一个安全项

`miniprogram/private.wxe3380ec60a48931d.key` 是**小程序代码上传密钥**，
谁拿到它就能上传新版本。本仓库的 `.gitignore` 已经忽略了 `*.key` / `private.*.key`
（确认过它没有被提交进版本库），所以只需注意：

- 不要把整个 `miniprogram/` 目录打包发给别人（密钥在里面）；
- 换电脑时用后台「重置」重新生成一份，而不是复制旧文件；
- 如果发现它曾经出现在公开仓库或聊天记录里，立刻到小程序后台
  「开发管理 → 开发设置 → 小程序代码上传密钥」重置。
