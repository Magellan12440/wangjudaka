## 1. 本地跑起来（5 分钟）

```bash
# 1) 起后端（默认 8787，mock 模式不烧算力）
cd server
npm install        # 首次
npm start

# 2) 起一个能跑全链路的演示数据（可选，方便直接看到有作品）
npm run smoke:mini   # 会自动建项目、生成总谱、点亮前 6 个节点后退出（用临时数据目录，不影响 data/）
```

微信开发者工具：

1. 导入项目 → 目录选 **`miniprogram/`**（不是仓库根目录）
2. AppID 先选「测试号」即可编译运行
3. 详情 → 本地设置 → 勾选 **不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书**
4. 编译后即可看到首页；点「一句话开剧」可跑完整创作流程

> 若首页一直转圈：确认后端 `http://127.0.0.1:8787/health` 返回 200，且 `miniprogram/config.js` 的 `baseUrl` 与之一致。

## 4. 提交审核（照着点）

1. 上传代码：开发者工具右上角 **上传** → 版本号 `4.1.0`，备注「网剧大咖 V4.1 首版」；
   或用命令行 `cd server && npm run mini:upload -- --version 4.1.0 --desc "网剧大咖 V4.1 首版"`
2. 小程序后台 → 管理 → 版本管理 → 开发版本 → **提交审核**
3. 填写审核信息：
   - **功能页面路径**：`pages/index/index`
   - **测试账号**：不需要（微信授权登录，无账号密码）
   - **补充说明**（直接抄）：

     > 本小程序面向内容创作者，提供 AI 辅助的网剧/短剧创作工具：输入一句话创意 → 生成导演总谱/剧本/分镜 → 管理角色资产 → 整理交付材料 → 跟踪分发状态。
     > 登录使用微信授权，无独立账号体系。生成的图片、视频、剧本均已按《人工智能生成合成内容标识办法》添加显式标识（片头 3 秒提示 + 封面角标）与隐式标识（元数据），并在「我的 → AI 生成内容说明」中完整披露。
     > 内容安全已接入微信 msgSecCheck / imgSecCheck，创作输入全量机审。
     > **注意：当前版本充值入口未开放（或：已接入微信虚拟支付，仅支持微信内支付）**，无站外支付、无诱导分享。

4. 审核时长通常 1–3 个工作日；被驳回按第 6 节对照修改后重新提交

## 5.5 管理后台与增长运营（上线后每天会用）

**后台入口**：`https://<你的域名>/admin.html`（本地为 `http://127.0.0.1:8787/admin.html`）
**登录方式**：输入服务端 `ADMIN_TOKEN`（在 `server/.env.local`）。令牌只存当前标签页会话，关页即清；未配置令牌时后台整体拒绝访问。

| 面板 | 你能做什么 |
|---|---|
| 经营概览 | 看有效档次、兑换码存量、用户余额与消耗 |
| 充值档次 | 新建/修改点数、**赠送福利**、售价、排序、上下架（改完小程序「我的」页即时生效，不用发版） |
| 兑换码 | 批量生成（面额+赠送+有效期+次数）、导出清单、作废、查使用明细 |
| 邀请裂变 | 调奖励额度、每日笔数上限、同 IP 上限、新用户窗口、是否需完成作品；逐条判定无效（已发奖励自动扣回） |

**邀请裂变的合规注意**：奖励是「点数」不是现金，且**不以分享为发奖条件**（好友凭邀请码注册并完成作品才发），
文案里不要出现「分享到 3 个群」「邀请必得现金」这类表述，否则容易被判诱导分享。若审核仍质疑，
可先在小程序里隐藏邀请入口（删掉 `pages/mine/mine.wxml` 的邀请菜单项即可），审核通过后再放出。

**续集怎么用**：打开任意剧集 → 顶部「拍下一季」→ 自动继承风格与角色设定（不继承上一季画面）→ 生成新一季总谱与流水线。
第二季的角色资产归属第二季项目，可继续开第三季；资产血缘可在项目详情/接口 `assets/lineage` 查。

## 6. 常见驳回点与对应改法

| 驳回理由 | 原因 | 改法 |
|---|---|---|
| 服务类目与实际功能不符 | 类目只选了「工具」 | 后台补「文娱 > 其他」或按提示补深度合成类目材料 |
| 缺少隐私保护指引 / 收集信息未声明 | 后台未声明「用户输入内容」 | 按第 2 节第 6 项补全，确保与 `pages/legal/legal` 文本一致 |
| 涉及 AI 生成内容未标识 | 审核员看不到标识 | 在「补充说明」里写明片头 3 秒标识 + 封面角标 + 元数据隐式标识，并截图附上 |
| 虚拟支付违规 | iOS 走了站外支付/跳转 | 本工程只用 `wx.requestVirtualPayment`，确认没有其它支付跳转；未开通就先关充值入口 |
| 诱导分享 / 强制关注 | 分享按钮文案带诱导 | 当前分享文案为「网剧大咖 · 一句话，开一部网剧」，无诱导，保持即可 |
| 打开即白屏 | `baseUrl` 还是 127.0.0.1，或域名没加白名单 | 见第 3 节自检第 2、3 项 |
